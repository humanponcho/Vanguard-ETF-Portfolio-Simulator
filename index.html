Currency Risk Note

This portfolio includes ETFs priced in USD but held in GBP. Returns may fluctuate based on GBP/USD exchange rates. A weaker GBP increases portfolio value, while a stronger GBP reduces it (all else equal).

Hedging Options

If you want to reduce exposure to currency swings, consider using currency-hedged share classes (e.g. VUAG GBP-hedged) or adding positions in UK/GBP-denominated bond funds. These typically have slightly higher costs but smooth out FX volatility.

Methodology and Assumptions

Assumptions

  • Expected Returns: Based on historical averages for each asset class.
  • Volatility: Derived from historical standard deviations of returns.
  • Correlation: Assumes low correlation between equities and bonds, moderate correlation between bonds and gold.
  • Rebalancing: Portfolio is assumed to be rebalanced annually to maintain target allocations.
  • Inflation: Simulations do not account for inflation-adjusted returns.

Methodology

The simulator uses a Monte Carlo simulation approach to project potential portfolio outcomes. Key steps include:

  1. Randomly generating annual returns for each asset class based on expected return and volatility.
  2. Calculating portfolio returns by weighting asset class returns according to the allocation.
  3. Repeating the process for the specified number of simulations to generate a range of outcomes.

Note: These projections are not guarantees of future performance and are subject to market risks.
